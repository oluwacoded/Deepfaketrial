# Access-code gate (Teddy MFG paid app)

- The paywall activates ONLY when DATABASE_URL is present (the always-on Replit
  host). On the free Colab GPU clone there is no DB, so the app runs fully OPEN.
  **Why:** smooth DFM needs the free Colab T4 GPU; gating it there defeats the
  product. Money is collected only on the stable Replit host. Keeping it
  conditional lets one `colab-gpu` codebase serve both hosts.
  **How to apply:** anything that gates behavior keys off `auth.enabled()`
  (pg8000 driver present AND DATABASE_URL); never assume the gate is always on.

- The call GUEST surface MUST stay public: `/call/<room_id>`,
  `/api/room/<room_id>`, the `/socket.io` handshake, static assets, and the
  WebRTC signaling socket events (webrtc_offer/answer/ice, end_call) plus
  connect/disconnect. Guests open a shared link with no code.
  **Why:** the person being called is not a subscriber; forcing a code there
  breaks the core "share a call link" feature.
  **How to apply:** gate `/` and `/api/*` via before_request, but protect the
  paid COMPUTE by gating the `frame` socket event itself — do NOT blanket-reject
  the socket `connect` handler or guests can't signal.

- Session model: a valid subscription stores `access_exp` (unix ts) in the
  signed Flask session; the frequent status poll validates by expiry from the
  session (no per-request DB hit). SECRET_KEY MUST be a real SESSION_SECRET when
  the gate is on — the app fails closed at startup otherwise, because a
  hardcoded fallback key would let anyone forge a paid cookie.

- Codes: `TMFG-XXXX-XXXX`, stored in Postgres (pg8000), status unused→active,
  expiry set on first redeem (tier days). Generated by an owner-only Telegram
  long-poll bot (DM-only; admin bound to sender user id).
